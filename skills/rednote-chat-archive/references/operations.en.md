# Operations and publishing

Run Python3.10+ python3 app.py in the checkout; visit http://127.0.0.1:8765/. Ctrl+C stops. Standard library only; ffmpeg/ffprobe for conversions; Node optional for syntax checks. REDNOTE_SOURCE_DB overrides unique source discovery. Grant required macOS runner access rather than disabling system protections. CLI export requires --user; no contact is seeded.

Frontend edits refresh; Python edits restart only your own service. Restart invalidates memory sessions but preserves passwords/data. A dead localhost URL usually means the server stopped. Media scans native archives and skips cached files; inspect failure reports because cached includes profiles/emoji.

Tests: test_contacts.py (synthetic schema),test_backup_delete.py (exclusive/shared assets),test_ai_chat.py (retention/isolation/races),test_providers.py (routes/key separation),test_app.py (temporary HTTP/password/cursor/timeline),node --check static/app.js. Do not remove live passwords, mutate real records, or send private data to test.

Publication requires explicit authorization and staged-file review excluding data/,secrets,personal paths,identities,screenshots/media and logs. .gitignore does not clean history. No license without owner choice. Maintain both READMEs, skill guides and Chinese/English references together.
