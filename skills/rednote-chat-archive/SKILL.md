## 必须保留的边界

1. 原小红书数据库只读。用 SQLite backup API 获取一致快照，不能只复制运行中的 `.db` 而忽略 WAL，也不能改动原 App 数据。
2. 真实消息存入 `data/chats.sqlite3`。AI 消息及保存时效存入 `data/ai_chats.sqlite3`。不能把 AI 回复混进真实消息、真实导出或原小红书。
3. 页面只监听 `127.0.0.1`。密码锁必须保护数据接口和附件，不是单纯隐藏 DOM。密码不等于磁盘加密。
4. 联系人公开小红书号与24位内部 ID 不同。依赖明确的身份字段、缓存关联或内部 ID 匹配，不能只按昵称猜测；无法识别时提示打开主页/聊天或提供主页链接。主页短链接只读取首次跳转并校验小红书主页域名；不跟随到登录页，不按昵称绑定账号。
5. 更新只读取 Mac 已加载的记录。说明实际时间范围，不能把“本地全部”声称为“服务器全部”，不能承诺恢复删除记录。
6. 模型请求只向用户选择并授权的服务发送当前会话的必要样本。密钥只在服务端使用，不回传、打印、写入示例或提交 Git。
7. AI 回复明确显示 `名字-AI`。只模拟表达风格，不声称是真人、代表本人或知道其当下感情。
8. 用户授权增加功能不等于授权发布仓库、删除真实记录、充值或向小红书发消息。保持这些动作各自的授权边界。

## 执行工作

- 先定位现有文件和相关调用，再做最小且完整的修改。不要继续无限追加互相覆盖的 CSS；较大改动时整理最终有效规则，保留已确认样式。
- Python 服务使用标准库，前端是原生 HTML/CSS/JS。除任务确有必要，不引入框架或改变部署方式。
- 样式和前端改动刷新即可。Python 模块改动需重启服务；仅停止本次自己启动的服务，重启会使8小时登录会话失效，密码及数据保留。
- 界面验证优先使用虚构消息和模拟 AI 的测试页，避免为测试发送真实私人聊天、产生模型费用或修改真实密码。
- 备份任务按会话执行，新增会话后自动切换；任务失败显示原因，不把部分附件失败当成完整备份成功。
- 异步 UI 必须处理超时、错误、会话切换、锁定和过期响应。向上追加消息保持锚点，避免回到底部打断阅读。

## 功能变动后的文档同步

每次新增、修改或移除功能，在同一任务中更新项目 README.md、此 SKILL.md 及受影响的 references。README 面向使用者说明最终行为；Skill 维护当前能力、约束和后续开发决策；具体参数、接口与算法细节放对应参考文档。检查旧描述、默认值和限制是否仍成立，不仅在末尾追加新说明。纯样式或文案变更在产品参考中记录最终状态，主文件可简要更新维护摘要，避免重复细节。

消息时间统一按北京时间及周一周界限格式化：今天只显示时分秒，本周其他日显示周几与时分秒，非本周显示YYYY-MM-DD与时分秒。

时间轴定位必须使用目标消息ID滚动到所选日期的第一条真实消息，不按页估算后滚到底部；无当日记录时说明实际定位日期。

当前 AI 发送交互：前端即时显示本人消息及对方头像、名字-AI、“回复中…”占位；成功后用已保存记录替换，失败恢复草稿。待回复节点不写入数据库，详见 AI 参考。

## 验证与交付

- 低影响文案/CSS变更不写镜像测试；检查实际选择器及页面即可。
- 改消息分页、密码、数据导出或模型路由时运行对应测试。参见运行参考中的测试范围。
- 自动删除要验证全部保存选项、默认1天、真实库不变，以及删除进行中 AI 请求后不会重新出现。
- 模型连通性优先使用不含私人历史的短测试。没有用户密钥时使用模拟响应并说明未验证真实调用。
- 文档只能描述已实现的行为。已知缺口单独列出，不把建议的改进写成当前能力。
- 用户要求上传 GitHub 时先检查候选文件，排除整个 `data/`、密钥、聊天附件、截图、缓存和本机标识。发布版使用REDNOTE_SOURCE_DB或唯一容器发现，且不预设联系人；忽略规则不会清除已跟踪文件或历史。

最终说明修改结果、必要操作和实质限制。不要输出聊天正文、完整密钥或密码散列来证明工作。

独立表情包使用CSS统一控制100×100px显示区域，保持图片比例及点击查看大图；避免JS内联尺寸覆盖样式。

每个会话更多菜单提供红色“删除备份”：输入当前访问密码二次确认（未设置密码需先设置），删除该会话的真实消息、原始元数据、AI记录、会话注册、项目导出及专属附件，并清理项目源数据库快照中的相关身份行。保留其他会话及共用附件；不修改小红书客户端源数据库，不删除外部另存文件。备份进行中禁止删除，密码错误不执行删除。删除无法撤销；重新添加会重新读取客户端仍保留的记录。

会话更多菜单根据最长选项自动撑开（width:max-content），浮层左右内边距均为6px、选项左右内边距均为14px，采用白色圆角浮层、细边框与柔和阴影，选项纵向排列，悬停浅灰底；更新、导出、删除AI记录和删除备份均配统一线框SVG图标，删除备份的图标及文字为红色。更多按钮为三点按钮，悬停、点击和展开时背景透明，键盘焦点保留轮廓提示。
